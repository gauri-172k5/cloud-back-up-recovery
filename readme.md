Cloud Backup and Recovery Management System

Project Description

This project is a web-based application developed using Python Flask and SQLite. It allows users to upload files, store backup records, view backup history, and restore or download previously uploaded files.

Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

Testing Tools Used
